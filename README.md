# MIKEFLIX

MIKEFLIX is a modern messaging app prototype inspired by WhatsApp. This project includes a mobile UI for chat and messaging, built with React Native and Expo.

## Features
- Chat list
- Messaging thread
- Group conversation
- Search bar
- Dark/light mode toggle
- Real-time-style UI prototype

## Run the app

```bash
npm install
npm start
```

Then open the Expo app on your device or start an emulator.

## Tech stack
- React Native
- Expo
- TypeScript
